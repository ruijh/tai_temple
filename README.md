# 岱庙三维漫游

Three.js r187 与 Vite 静态网站。项目包含岱庙三路院落、九个中轴站点和十一座可进入的殿宇。

## 运行

```powershell
npm.cmd ci
npm.cmd run dev -- --port 5173
```

浏览器打开 [本地站点](http://127.0.0.1:5173/)。`npm.cmd run build` 生成 `dist/`。可执行 `npm.cmd run preview` 验证生产构建。公开站点见 [GitHub Pages](https://ruijh.github.io/tai_temple/)。

## 操作

- 拖动旋转，滚轮或双指缩放。鸟瞰、中轴、总平面可切换。
- 通过中轴清单、小图、场景标记或建筑图录定位。在“殿宇”中可查看正殿、配殿与寝宫，“可入殿”列出所有可漫游殿宇。
- 殿内拖动转头，用 WASD、方向键或触屏方向按钮移动。每殿有独立的预设视点，Esc 或返回按钮退出至该殿外。

- 顶栏“碑刻”可按位置、年代、碑名、别名或已收录的碑文检索。点场景中的菱形定位代表性碑刻。带碑照的条目可放大、拖动查看，部分条目附碑文。
- 顶栏“楹联”可按殿宇、门坊、院落筛选，检索地点、题署和联句。详情附上下联、悬挂依据、实景或史料链接，可回到三维建筑位置。原悬挂处待考的旧联随文献收录。
- 顶栏「古树名木」收录九个树号。点「开始导览」沿「寻访千年古柏」六站查看档案，绿色三维标记可定位到有实景地标依据的古树。根位待核的站点只定位所在区域。双干连理与乾隆碑图可并排对读。
- “遗址与配属”可独立定位城门、回廊、耳房、池石及历史旧址。延禧殿等以旧址标记呈现，环咏亭使用低矮示意基址。
- 顶栏“泰山线路”可查看红门、天外村、东御道、桃花峪和天烛峰。南天门、中天门、东天门、北天门和玉皇顶可独立定位，点“返回岱庙”回到近景。
- 顶栏“摩崖石刻”可查阅红门经中天门、十八盘、南天门至玉皇顶的题刻，另含经石峪和日观峰。可按路段、题名、题署或已录刻文查找，点击照片可放大。图录内有“在泰山线路定位”的记录已对照岩面和地图节点，红门线也可按路段打开这些点位。

## 资料和模型

- `src/catalog.json` 摘取自工作区岱庙建模资料库。尺寸用核对后的地方志值，照片附文件页、摄影者及逐张许可。
- `src/data.js` 保存站点顺序及场景点位。X 向东，Y 向上，Z 向南，单位为米，正阳门中洞中心为工作原点。城域尺寸为 236.7 × 405.7 米。院落及建筑基点根据总平摹图与航拍估读，仍需现状测绘配准。
- 天贶殿采用核对后的重檐庑殿形制和主要尺寸。配天门、仁安门和后寝正宫的通高取自地方志。
- 主殿双层台基、面阔进深、屋顶类型和内外柱数有资料依据。独立殿内场景的柱位、藻井与神龛作形体示意。壁画为一张有署名的实拍局部，以独立参照展示。
- 新增室内有逐殿依据。三灵侯殿、太尉殿取地方志旧祀，东西寝宫与东御座东西配殿取开间记载，鲁班殿取复建报道。模型中净高、隔断及陈设依各殿证据标注为示意。
- 支路配房、植栽与泰山远景做概略表达。当前使用 WebGL 2，照片和历史图可在“三维漫游”页面的资料页查阅其来源。
- 泰山地形使用 Mapzen/Tilezen Terrain Tiles（中国区域高程底源为 NASA/USGS SRTM）。本地高程网格由 Terrarium z11 的 1689–1690、801–802 四幅瓦片重采样，另设构图压缩。红门至玉皇顶盘道与经石峪支线采用 OpenStreetMap 步道，其他线路按官方导览节点勾勒。山门几何与索道端点为示意。[高程数据及署名](https://registry.opendata.aws/terrain-tiles/) · [源数据署名](https://github.com/tilezen/joerd/blob/master/docs/attribution.md) · [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)

- 碑刻图录收录 169 条去重记录。通过「三维可定位」查看场景内石刻。场景建模要求有具体展位依据、对应碑文和可辨认的实拍碑面。只能核对到院、廊或墙的记录保存在图录，详情可查档案位置、录文和图像来源。
- 《望岳》诗碑及《秋兴八首》诗碑的释文与碑面位置，分别对照《泰山石刻大全》第四册第 644、637–643 页与泰山石刻档案。东碑廊《望岳》可按详情中的列序对照原书拓片。汉柏亭碑照引用 Huanokinhejo 的 CC BY-SA 4.0 摄影原图，可在站内放大并定位诗句。
- 「碑刻还原」从照片原站载入实拍，在浏览器内裁切和校正透视后贴到场景里。祥符碑和宣和碑使用碑阴，《秋兴八首》使用汉柏亭台基南墙的六块连碑。加载失败的碑面保留石质模型和原图入口，其他碑面可继续贴图。乾隆三十六年（1771）题回马岭诗碑可在图录查看录文并打开原档案。
- 网站通过原站链接引用实拍照片，构建包不包含照片文件。预览和放大查看优先使用原站提供的合适尺寸。各处实拍入口保留原图、出处和许可信息，加载失败时可直接打开原图或照片出处。浏览器对 CC BY-SA 原照作裁切和透视校正时，处理结果沿用原授权。
- 古树档案及三维相对位置依据见 `src/ancient-trees.js`。双干连理与乾隆碑图并排引用 H2v5o68z 的 CC0 照片。苍龙吐虬与唐槐抱子可在站内放大 rheins 拍摄的 CC BY 3.0 照片。测试中无法在站内直载的官方树照保留原图、出处和许可状态。
- 岱庙坊南北抱鼓石上的石狮及幼狮参照实景和旧馆导览。遥参坊铁狮与配天门铜狮用不同材质作示意。
